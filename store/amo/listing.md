# Firefox Add-ons listing — Internet's Dream

**Name:** Internet's Dream — Memory Saver
**Summary:** Save pages & selections into your private encrypted second brain.

**Description:**
Right-click any page or selected text → "Save to Dream". Search your
indexed memories from the popup. Requires the dreamcore backend running
locally (default http://127.0.0.1:8765, configurable).

Permissions used: storage (API base config), contextMenus, activeTab,
scripting (page metadata extraction only — no remote code).

**Categories:** Productivity, Privacy & Security
